**LLM-Powered Clinical Reporting with Quarto**

### Abstract
This session demonstrates how clinical reporting workflows can be enhanced through the integration of large language models (LLMs) with **Quarto**. We will showcase how analysis outputs from R and Python can be combined with AI-assisted narrative generation to produce cohesive, reproducible reports. The focus will be on building flexible pipelines that support both manual and automated workflows, enabling teams to balance efficiency with control.
